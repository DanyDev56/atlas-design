# Principes de conception

Les principes suivants guident toutes les décisions produit.

---

## 1. L'action avant l'information

Une donnée seule n'a pas de valeur.

Une donnée accompagnée d'une action est utile.

---

## 2. L'explication avant la prédiction

Atlas explique toujours pourquoi une recommandation est proposée.

La confiance est plus importante que la sophistication.

---

## 3. L'utilisateur garde le contrôle

Atlas conseille.

L'utilisateur décide.

Les automatisations restent explicables et maîtrisées.

---

## 4. Une donnée, plusieurs usages

Une information saisie une seule fois doit pouvoir être réutilisée partout.

Une facture peut alimenter :

- la trésorerie ;
- les prévisions ;
- les statistiques ;
- le Business Health ;
- l'Advisor.

---

## 5. Les événements racontent l'histoire

Les données décrivent l'état de l'entreprise.

Les événements racontent son évolution.

Cette chronologie constitue le cœur d'Atlas.

---

## 6. La simplicité est une fonctionnalité

Chaque écran doit réduire la charge mentale.

Si une fonctionnalité ajoute plus de complexité que de valeur, elle ne sera pas développée.
