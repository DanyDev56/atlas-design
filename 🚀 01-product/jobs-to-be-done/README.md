# Jobs To Be Done

## Objectif

Les Jobs To Be Done décrivent les véritables objectifs poursuivis par les utilisateurs.

Ils répondent à une question simple :

> Pourquoi utilise-t-il Atlas ?

La réponse n'est jamais :

> Pour créer une facture.

Mais plutôt :

> Pour être payé rapidement.

Cette distinction est fondamentale.

Atlas ne développe pas des fonctionnalités.

Atlas aide les utilisateurs à accomplir leurs objectifs.

---

## Format

Chaque Job To Be Done est rédigé selon la structure suivante :

> Quand...
>
> Je veux...
>
> Afin de...

Cette formulation permet de rester centré sur le problème utilisateur.

---

## Utilisation

Chaque nouvelle fonctionnalité doit répondre à au moins un Job To Be Done.

Si ce n'est pas le cas, sa pertinence doit être remise en question.

---

## Les grandes catégories

Les Jobs To Be Done sont répartis en six domaines :

- Trouver des clients
- Vendre une prestation
- Réaliser la mission
- Être payé
- Piloter son activité
- Développer son entreprise
