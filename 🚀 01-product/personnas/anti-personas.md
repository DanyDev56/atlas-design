# Anti-personas

## Objectif

Les anti-personas définissent les utilisateurs qu'Atlas ne cherche pas à servir pendant sa première phase de développement.

Cette exclusion est volontaire.

Elle permet de :

* limiter la complexité ;
* protéger la cohérence du produit ;
* concentrer les ressources ;
* éviter les fonctionnalités périphériques ;
* construire une excellente expérience pour une cible précise.

---

## Le commerçant avec stock

### Profil

Le commerçant vend des produits physiques et doit gérer :

* les stocks ;
* les fournisseurs ;
* les commandes ;
* les références ;
* les inventaires ;
* les retours ;
* les marges par produit ;
* les points de vente.

### Pourquoi Atlas ne le cible pas en V1

Ces besoins nécessitent un domaine métier spécifique.

Les intégrer trop tôt transformerait Atlas en ERP généraliste.

---

## L'entreprise industrielle

### Profil

L'entreprise industrielle gère :

* les achats ;
* la production ;
* les matières premières ;
* la logistique ;
* la maintenance ;
* les équipes ;
* les processus qualité.

### Pourquoi Atlas ne la cible pas

Son organisation et ses besoins sont trop éloignés de ceux d'un prestataire de services indépendant.

---

## La grande entreprise

### Profil

La grande entreprise possède :

* plusieurs équipes ;
* plusieurs niveaux hiérarchiques ;
* des procédures complexes ;
* des systèmes d'information existants ;
* des besoins avancés en gouvernance ;
* des exigences d'intégration importantes.

### Pourquoi Atlas ne la cible pas en V1

Atlas doit d'abord optimiser la prise de décision d'un indépendant ou d'une petite structure.

La gestion d'organisations complexes pourrait détourner le produit de sa mission initiale.

---

## L'utilisateur cherchant uniquement un outil gratuit

### Profil

Cet utilisateur cherche principalement :

* la création gratuite de factures ;
* le minimum réglementaire ;
* aucun accompagnement ;
* aucun pilotage ;
* aucun conseil.

### Pourquoi ce profil n'est pas prioritaire

La valeur d'Atlas repose sur :

* l'analyse ;
* la recommandation ;
* l'automatisation ;
* l'amélioration des décisions.

Atlas ne doit pas entrer dans une compétition fondée uniquement sur la gratuité.

---

## Le cabinet comptable

### Profil

Le cabinet comptable recherche :

* la tenue comptable ;
* la révision ;
* les déclarations fiscales ;
* la production des comptes ;
* la gestion de portefeuilles ;
* la conformité réglementaire complète.

### Pourquoi Atlas ne le cible pas

Atlas pourra collaborer avec des experts-comptables ou leur transmettre des données.

Il n'a pas vocation à remplacer leur logiciel métier.

---

## Le dirigeant recherchant un ERP configurable

### Profil

Cet utilisateur souhaite adapter précisément :

* chaque champ ;
* chaque workflow ;
* chaque permission ;
* chaque écran ;
* chaque règle ;
* chaque rapport.

### Pourquoi Atlas ne le cible pas

Une configuration illimitée augmente fortement la complexité du produit.

Atlas privilégie des parcours simples et opinionated, fondés sur les meilleures pratiques.

---

## Règle de protection du périmètre

Lorsqu'une fonctionnalité est demandée, l'équipe doit vérifier si elle répond à un besoin du persona principal.

Une fonctionnalité principalement destinée à un anti-persona doit être :

* refusée ;
* reportée ;
* isolée dans une future offre spécialisée ;
* ou traitée par une intégration externe.

Atlas ne doit pas devenir un produit universel.

Il doit devenir un produit exceptionnel pour une cible clairement définie.
