# Product Governance

## Objectif

Définir comment Atlas évolue.

La gouvernance ne décrit pas les fonctionnalités.

Elle décrit les règles qui encadrent leur création, leur évolution et leur suppression.

Le but est de garantir une croissance maîtrisée du produit.
