# Expérimentation

Toute expérimentation possède :

- une hypothèse ;
- une métrique ;
- une durée ;
- un critère d'arrêt.

Les résultats sont documentés.

Les expérimentations ne deviennent pas permanentes sans validation.

## Expérimentations tarifaires

Une expérimentation de pricing précise en plus :

- le persona et le niveau d'activation requis ;
- le prix, la période et le packaging effectivement présentés ;
- la présence éventuelle d'une remise ;
- la décision observée : paiement, précommande ou refus motivé ;
- les effets sur conversion, rétention, support et marge ;
- les règles de traitement équitable entre cohortes.

Le produit est montré avant la question de prix. Les montants testés ne sont pas
personnalisés à partir de données sensibles ou d'une estimation opaque de la
capacité à payer. Aucun faux compte à rebours, prix barré permanent ou coût
caché ne peut être utilisé pour améliorer artificiellement la conversion.

La stratégie, les hypothèses et les critères de passage à un tarif public sont
définis dans
[`pricing-strategy.md`](../../fondation/product/pricing-strategy.md).
