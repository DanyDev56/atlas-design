# Product Blueprint

Le Product Blueprint représente la vue d'ensemble du produit.

Il répond notamment aux questions suivantes :

- Quels sont les modules ?
- Comment l'utilisateur navigue-t-il ?
- Quels sont les principaux parcours ?
- Comment les modules interagissent-ils ?
- Quelles sont les intégrations ?
- Quelles API sont exposées ?

Ce document est la porte d'entrée pour toute personne rejoignant le projet.
