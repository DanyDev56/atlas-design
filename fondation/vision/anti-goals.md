# Anti-objectifs

Les anti-objectifs définissent ce qu’Atlas ne cherche pas à devenir.

Ils protègent le produit contre la dispersion, la complexité inutile et les demandes incompatibles avec sa mission.

---

## Atlas ne devient pas un ERP généraliste

Atlas n’a pas vocation à couvrir tous les processus d’une entreprise.

Le produit ne cherche pas à gérer nativement :

- la production industrielle ;
- les chaînes logistiques complexes ;
- les achats fournisseurs avancés ;
- les stocks multi-entrepôts ;
- la paie ;
- les ressources humaines complètes ;
- la maintenance industrielle.

Les besoins éloignés du cœur du produit doivent être couverts par des intégrations lorsque cela est pertinent.

---

## Atlas ne devient pas un logiciel comptable complet

Atlas peut préparer, structurer et transmettre des données financières.

Il peut notamment :

- gérer les devis et factures ;
- suivre les paiements ;
- produire des exports ;
- se connecter à des solutions comptables.

Atlas ne remplace pas :

- un expert-comptable ;
- une solution de tenue comptable complète ;
- les contrôles fiscaux et réglementaires spécialisés.

---

## Atlas ne devient pas un simple outil de facturation

La facturation est une fondation indispensable, mais elle n’est pas la différenciation principale.

Atlas ne doit pas concentrer toute son évolution sur :

- les modèles de documents ;
- les options décoratives ;
- les réglages administratifs ;
- la parité fonctionnelle avec chaque logiciel de facturation.

Chaque évolution de Billing doit également servir la compréhension, la décision ou l’action.

---

## Atlas ne devient pas un tableau de bord passif

Afficher davantage de graphiques n’est pas un objectif.

Un indicateur doit avoir une utilité identifiable.

Atlas évite :

- les métriques décoratives ;
- les graphiques sans interprétation ;
- les tableaux surchargés ;
- les indicateurs non actionnables ;
- les chiffres dont la méthode de calcul n’est pas compréhensible.

---

## Atlas ne devient pas infiniment configurable

Une configuration avancée augmente souvent :

- la charge mentale ;
- le risque d’erreur ;
- le coût de maintenance ;
- l’incohérence entre utilisateurs.

Atlas privilégie :

- des comportements intelligents par défaut ;
- des choix limités mais pertinents ;
- une personnalisation progressive ;
- des configurations guidées.

Atlas ne cherche pas à satisfaire chaque processus particulier par une option supplémentaire.

---

## Atlas ne développe pas une fonctionnalité uniquement parce qu’un concurrent la possède

La parité concurrentielle n’est pas une stratégie.

Une fonctionnalité doit être justifiée par :

- un besoin utilisateur réel ;
- la mission ;
- une capability ;
- une valeur mesurable ;
- un avantage stratégique.

---

## Atlas ne collecte pas des données sans utilité

Chaque donnée demandée doit avoir un usage clair.

Atlas ne collecte pas une information uniquement parce qu’elle pourrait éventuellement servir plus tard.

La collecte doit être :

- nécessaire ;
- proportionnée ;
- expliquée ;
- utile à l’utilisateur.

---

## Atlas ne remplace pas le jugement humain par défaut

L’intelligence artificielle et les automatisations ne doivent pas masquer les décisions importantes.

Atlas évite :

- les actions irréversibles silencieuses ;
- les recommandations impossibles à expliquer ;
- les décisions automatisées sans consentement ;
- les prédictions présentées comme certaines.

---

## Atlas ne cible pas toutes les entreprises

La première cible reste constituée des indépendants et petites entreprises de services.

Atlas n’optimise pas prioritairement le produit pour :

- les grandes entreprises ;
- les organisations multi-filiales complexes ;
- les industries avec stocks importants ;
- les équipes disposant déjà d’un ERP complet ;
- les utilisateurs recherchant uniquement un outil gratuit de facturation.

---

## Atlas ne sacrifie pas la cohérence pour accélérer

Une livraison rapide ne justifie pas :

- la duplication d’un concept ;
- la violation d’un invariant ;
- la création d’une dépendance circulaire ;
- l’utilisation d’une terminologie contradictoire ;
- l’absence de traçabilité ;
- un comportement impossible à expliquer.

La rapidité est utile uniquement lorsqu’elle ne dégrade pas durablement le produit.
