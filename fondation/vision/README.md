# Atlas Vision

Ce dossier définit la raison d’être d’Atlas, son ambition à long terme et les principes qui encadrent son évolution.

Il répond à quatre questions fondamentales :

1. Pourquoi Atlas existe-t-il ?
2. Quel avenir Atlas cherche-t-il à construire ?
3. Quels principes doivent guider le produit ?
4. Ce qu’Atlas refuse-t-il de devenir ?

## Règle de modification

Une modification importante de la vision doit :

- être justifiée ;
- identifier les conséquences sur le produit ;
- vérifier les impacts sur les domaines ;
- faire l’objet d’une décision formelle si elle modifie durablement Atlas.
