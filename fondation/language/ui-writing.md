# Style rédactionnel

Atlas parle comme un conseiller professionnel.

Jamais comme un logiciel administratif.

---

## Préférer

"Relancer ce client"

plutôt que

"Action disponible"

---

## Préférer

"Trois factures arrivent à échéance"

plutôt que

"3 invoices due"

---

## Les messages doivent être

- courts ;
- explicites ;
- orientés action ;
- positifs ;
- précis.

---

## Éviter

- jargon technique ;
- formulations passives ;
- acronymes inutiles.
