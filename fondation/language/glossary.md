# Glossaire officiel

| Terme | Définition |
|---------|------------|
| Workspace | L'espace de travail d'une entreprise. |
| Client | Une personne ou une organisation avec laquelle une relation commerciale existe. |
| Opportunity | Une vente potentielle. |
| Quote | Une proposition commerciale. |
| Invoice | Une facture. |
| Payment | Un règlement reçu. |
| Recommendation | Une action proposée par l'Advisor. |
| Business Health | L'état global de santé de l'entreprise. |
| Timeline | La chronologie des événements. |
| Activity | Un événement enregistré dans Atlas. |
| Signal | Une information détectée automatiquement. |
| Automation | Une règle exécutée automatiquement. |
| Insight | Une information interprétée à partir des données. |
