# Decision Log

## Pourquoi

Chaque décision importante doit être documentée.

Les décisions oubliées finissent toujours par être rediscutées.

Le Decision Log évite cela.

---

## Objectifs

Conserver :

- le contexte ;
- les alternatives ;
- les raisons ;
- les conséquences.

---

## Ce qui mérite une décision

- architecture ;
- UX ;
- IA ;
- sécurité ;
- modèle métier ;
- technologies ;
- intégrations.

Les changements mineurs ne nécessitent pas de décision formelle.
