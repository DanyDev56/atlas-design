# Atlas Foundation

La fondation contient les éléments structurants et durables d’Atlas.

Elle constitue la source de vérité pour :

- la vision ;
- les principes produit ;
- la terminologie ;
- les règles métier ;
- les domaines ;
- les décisions structurantes ;
- les règles d’architecture et d’ingénierie.

---

## Hiérarchie des documents

En cas de contradiction, l’ordre de priorité suivant s’applique :

1. Constitution
2. Vision et principes
3. Décisions acceptées
4. Invariants des domaines
5. Product Language
6. Domain Map
7. Product Strategy
8. Blueprint
9. Roadmap et documents d’évolution

Un document de niveau inférieur ne peut pas contredire un document de niveau supérieur.

---

## Modification des fondations

Toute modification significative doit :

- expliquer la raison du changement ;
- identifier les documents affectés ;
- mettre à jour les références associées ;
- créer une décision formelle lorsque le changement est structurant.

Les fondations doivent évoluer lentement et volontairement.
