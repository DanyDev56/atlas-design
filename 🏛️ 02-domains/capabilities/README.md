# Product Capabilities

## Pourquoi ce domaine existe

Les domaines métier décrivent les données.

Les fonctionnalités décrivent les interfaces.

Les Capabilities décrivent ce qu'Atlas sait réellement faire.

Une capability peut être utilisée par plusieurs domaines.

Exemple :

Détecter un risque de trésorerie.

Cette capacité peut être utilisée par :

- Advisor
- Dashboard
- Notifications
- Business Health
- API

Elle n'appartient à aucun écran.

---

## Les six capacités fondamentales

Atlas possède actuellement six grandes capacités :

- Détecter
- Prédire
- Recommander
- Expliquer
- Automatiser
- Apprendre

Toutes les évolutions du produit devront renforcer au moins l'une d'entre elles.
